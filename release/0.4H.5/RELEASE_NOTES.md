# Parallels X: Clash of Souls 3.0R — 0.4H.5 Candidate

This candidate release contains the same shared Chapter 1 game for all three required platforms:

- Nintendo 3DS homebrew (`.3dsx`)
- macOS universal application disk image (`.dmg`)
- Linux x86_64 native executable package (`.tar.gz`)

The release also includes SHA-256 checksums and the complete new-chat handoff document.

Verification completed before release:

- 5/5 shared automated test suites passed.
- The 3DS file is recognized as a valid Nintendo 3DS homebrew application.
- The macOS DMG checksum and disk-image structure verified successfully.
- The native Linux build and its shared tests passed on GitHub's Ubuntu runner.

This remains a candidate until the Chapter 1 acceptance gate and real Old 3DS hardware review are complete.
