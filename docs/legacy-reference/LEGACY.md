# Legacy reference

The word **Legacy** in 3.0R development means exactly:

`Parallels-X-Prototype-2.9A.40.7.1.1-Chapter-2-Optional-Fight-Hub-Return-Fix`

Use Legacy as the primary reference for:
- gameplay feel,
- map shape/design,
- hub flow,
- arena/combat language,
- cutscene placement and story-to-gameplay cadence,
- side-quest foundation,
- chapter identities,
- character voice when still canon.

Do not copy its patched architecture or obsolete story lore into the remake.
