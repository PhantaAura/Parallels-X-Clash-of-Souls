# Parallels X 3.0R — Review Context

Review this as a **remake of an existing game identity**, not as a blank-slate pitch.

Current build: **Mac 0.4F.1 — Legacy Presentation + Continuity Lock**.

## Please critique

- whether Press Start → one-mode carousel → Story route carousel reads as the old Parallels X menu idea remade rather than replaced;
- whether Story So Far is visibly contextual to Story Mode and readable as an optional 5–7 minute recap;
- whether the complete Chapter 1 path reads as the same Legacy adventure;
- whether the river/Object Swap interaction reads cleanly;
- whether the restored Legacy `CHOOSE A ROUTE` panel and subsequent physical Main / Forest / Cliff traversal are clear;
- whether the shared `ExplorationRegistry` keeps content separate from the engine cleanly enough for Mac + Old 3DS XL;
- hotbar chronology: only Fire Blast / Object Swap / Lens are visible; unavailable techniques are absent;
- perspective/depth correctness and whether the primitive 3D world is a maintainable base for authored assets;
- timed shared combat feel and remaining presentation/tuning differences;
- state-machine/save hazards, maintainability problems and likely jank;
- any material Mac/Linux layout mismatch.

## Do not treat as final art

0.4F.1 uses replaceable procedural character poses, recap stills, world-space humanoids and primitive environment meshes. Final character models, authored environment meshes, portrait art, facial presentation, audio and animation are not present yet. `Jimmy.glb` is retained but is not currently rendered.

## Screenshot set

The files under `review/screenshots/` were rendered by the graphical Linux shell through SDL software rendering. They cover Press Start; Story, Arena and Online carousel states; Story So Far; fresh Rrvvfo and discovered Bark/Wade/Virek character states; combat manual; exploration HUD; combat HUD; and dialogue.

They validate shared layout/state and are not a substitute for native Mac approval.

## Protected direction

- one shared engine across all chapters/routes;
- continuous Story Mode with whole-chapter-only replay and no mission selector/replay;
- Legacy gameplay/map identity;
- current story canon where Legacy conflicts;
- Organization of the Red (`organization_red`) as the Lost-Year faction, with the old development alias used only for save migration;
- compact, interconnected, activity-dense world design;
- Tournament Card, Old Man's Potion quest and Ryuzankaro remain protected content;
- Web/mobile gameplay targets are intentionally out of scope;
- macOS leads development while Old 3DS XL is tested alongside it.

Suggestions are welcome, but distinguish bug/clarity criticism from proposals that would fundamentally redesign the game.
